## 🚀 快速启动

### 启动服务器

支持多人对战，请使用 Node.js 启动服务器：

```bash
# 进入项目目录
cd doudizhu

# 安装依赖
npm install

# 启动服务器
npm start
```

访问 `http://localhost:3000` 即可开始游戏。

### 方法一：直接打开 (单机模式)
由于使用了 ES6 模块，需要通过 HTTP 服务器运行（确保已安装 Python 3 或 Node.js）：

```bash
# 进入项目目录
cd doudizhu

# 使用 Python 启动简易服务器
python3 -m http.server 12000

# 或使用 Node.js 的 http-server
npx http-server -p 12000
```

然后在浏览器中访问：`http://localhost:12000`

### 方法二：使用 Live Server
如果使用 VS Code，可以安装 Live Server 插件，右键 `index.html` 选择 "Open with Live Server"。

### 测试

项目包含基于 Jest 的单元测试。确保已安装 Node.js 和依赖：

```bash
# 安装依赖
npm install

# 运行测试
npm test
```

## 🎮 游戏规则

### 发牌
- 一副牌共54张（包含大小王）
- 每人发17张，剩余3张为底牌

### 叫地主
- 从随机玩家开始叫分
- 可以叫1分、2分、3分或不叫
- 叫分最高者成为地主，获得底牌
- 如果都不叫，重新发牌

### 出牌
- 地主先出牌
- 必须按牌型出牌，后出的牌必须比前面的大
- 如果无法或不想出牌，可以选择"不出"
- 当连续两人不出时，重新开始新一轮

### 胜负判定
- 先出完手牌的一方获胜
- 地主获胜则地主赢，农民获胜则两个农民赢
- 春天：地主在农民没出牌的情况下出完，倍数翻倍
- 反春天：农民在地主只出一手牌的情况下出完

### 倍数
- 基础倍数为叫分数
- 每出一次炸弹或王炸，倍数翻倍
- 春天或反春天，倍数翻倍

## 🛠 技术实现

### 模块化架构
项目采用 ES6 模块化开发，各模块职责清晰：

| 模块 | 职责 |
|------|------|
| [`card.js`](js/card.js) | 定义扑克牌数据结构，包括花色、牌面值、权重等 |
| [`deck.js`](js/deck.js) | 牌组管理，包括洗牌、发牌、手牌管理 |
| [`rules.js`](js/rules.js) | 牌型分析和规则判断，支持所有斗地主牌型 |
| [`player.js`](js/player.js) | 玩家基类和AI玩家实现 |
| [`game.js`](js/game.js) | 游戏流程控制，状态管理，UI交互 |
| [`animation.js`](js/animation.js) | 动画效果管理 |
| [`sound.js`](js/sound.js) | 音效和语音管理 |

### AI策略
AI采用简单的策略模式：
- 叫分：根据手牌强度（大小王、2、炸弹数量）决定
- 出牌：优先出小牌和组合牌，保留大牌
- 跟牌：寻找能打过上家的最小牌组

### 牌型判断算法
使用权重分组法进行牌型识别：
1. 对手牌按权重分组
2. 检查各组牌数量分布
3. 验证是否满足特定牌型规则
